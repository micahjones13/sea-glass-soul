# Seaglass Soul

Handcrafted sea glass art & resin creations — React + Tailwind rebuild of [seaglass-soul.com](https://seaglass-soul.com/).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Home / About
- `/gallery` — Artwork carousel
- `/contact` — Email CTA
